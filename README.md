SmartAttend is a web app for tracking student attendance, marks and assignments in one place. It has separate dashboards for admins, teachers and students, so each person sees only what they need.

Features:

Attendance: teachers mark Present, Absent, Leave or Medical for each class, and can edit it later if the admin allows. Students see their percentage per subject, with low-attendance warnings that tell them how many classes they need to catch up.
Marks: teachers create assessments such as quizzes, mid-terms and finals, enter marks, and publish results when ready. Students see weighted subject percentages, grades and class averages.
Assignments: teachers post assignments and track each student as Pending, Submitted, Late or Missing, with marks and feedback. Students see due dates and an overdue badge.
Academic standing: each student gets a dashboard with attendance, marks and assignment rings and an On track, Needs attention or At risk status with plain-language reasons.
Student overview: admins and teachers see every student with their status and can filter to at-risk students.
Report cards: a printable A4 progress report for each student that can be saved as a PDF.
Admin controls: approve or reject signups, manage students, teachers and subjects, and set the minimum attendance and marks. The admin can also switch individual teacher and student permissions on or off.
Reports: attendance reports with date filters, a defaulters list and CSV download.

Tech stack: Python, Flask, SQLite, vanilla JavaScript, Chart.js. It has a responsive design that works on phones.
